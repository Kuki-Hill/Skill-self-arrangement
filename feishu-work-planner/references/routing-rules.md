# 落点路由与紧急度矩阵

## 1. 三落点路由表

| 落点 | 何时写 | 判据 |
|---|---|---|
| **任务台账（Base）** | **永远写** | 唯一真源，甘特/日历/看板视图自动呈现 |
| **飞书日历日程** | P0 必写；P1 且带里程碑或用户明确要求时写；P2/P3 默认不写 | 有明确时间点的节点（评审、冻结、演示、会议）优先写 |
| **飞书任务待办** | P0/P1/P2 写；P3 默认不写 | 需要提醒、有具体执行动作的任务才值得占待办栏 |

覆盖开关（`intake.py`）：`--calendar` / `--no-calendar` / `--task` / `--no-task` / `--only-base`。

**反面模式**：把所有任务都塞进待办栏——待办是「今天要动手」的清单，长期任务只进台账（甘特图看全貌），临近才建待办。

## 2. 紧急度矩阵

| 级别 | 含义 | 默认工期（反推开始日） | 日历日程 | 待办 | 提醒 |
|---|---|---|---|---|---|
| **P0** | 紧急且重要，有硬截止 | 1 天 | ✅ 必建（全天或时段） | ✅ | 提前 1 天 + 提前 2 小时（日历）／提前 1 天（待办） |
| **P1** | 重要，有明确节点 | 3 天 | △ 带里程碑时建 | ✅ | 提前 1 天 |
| **P2** | 常规推进 | 7 天 | ❌ | ✅ | 提前 2 小时 |
| **P3** | 长期/弹性 | 14 天 | ❌ | ❌ | 无 |

- 用户没说紧急度 → 默认 **P2**，并在回报里标注「按 P2 处理，可调整」。
- 用户给了中文（紧急/高/中/低、很急/不急）→ 映射 `紧急→P0`、`高→P1`、`中→P2`、`低→P3`。
- 「下周再说」「有空做」→ P3；「明天必须」「deadline」→ P0。

## 3. 工期与日期推导

```
已知截止 D，未知开始：
  start = D - duration_days(P)         # 按上表
  if start < today: start = today      # 不允许开始日期早于今天
已知开始 S，未知截止：
  due = S + duration_days(P)
两者都未知：
  due = today + duration_days(P)，start = today
```

- 用户给了时间段（"11/03 到 11/06"）→ 直接用，不再推导。
- `start` 必须 ≤ `due`，脚本会强制校正并写进 `parse_warnings`。
- 甘特图**必须有起止两个日期**才有时间条；缺开始日期的任务不会出现在甘特条上——这就是必须推导的原因。

## 4. 时间表达式解析

| 输入 | 解析 |
|---|---|
| `2026-11-06` / `2026/11/06` | 直接 |
| `11-06` / `11/06` | 当年；若早于今天则次年 |
| `今天` / `明天` / `后天` / `大后天` | 相对 |
| `3天后` / `2周后` / `+2d` | 相对 |
| `下周三` / `本周五` / `周一` | 最近的未来那个周几；「本X」若已过则取下周 |
| `月底` / `年底` | 当月最后一天 / 12-31 |
| `11-06 14:00` | 带时刻，日历用；台账仍存日期 |

解析不出 → `due_date = null` + `parse_warnings` 提示，**必须先问用户**再写。

## 5. 去重与更新

写入前查重，避免同一任务录两遍：

```bash
lark-cli base +record-search --base-token <B> --table-id <T> \
  --keyword "<任务名称前 12 字>" --search-field "任务名称" --as user --format json
```

命中且截止日期相同 → **更新而非新建**（`+record-upsert --record-id <rec>`），并把日历/任务链接写回同一行。
命中但截止日期不同 → 视为新任务，标题加后缀区分。

## 6. 状态流转

```
未开始 → 进行中 → 待验收 → 已完成
            ↓
          阻塞（需备注原因）
```

- 只改 Base 的「状态」字段即可，看板/甘特自动跟随。
- 任务完成后同步把飞书任务置完成：`lark-cli task +complete --task-id <guid> --as user`。
- 台账里的「飞书任务链接」是反查钥匙，别清空。
